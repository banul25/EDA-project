# Amazon Prime Video Content Analysis & EDA

An exploratory data analysis (EDA) project focused on the **Amazon Prime Video content catalog**.

This project analyzes movies and TV shows based on content type, genres, ratings, release years, and other attributes to identify patterns and trends within the streaming platform's library.

## 📁 Project Structure

```text
amazon-prime-EDA-project/
│
├── EDA_of_amazon_prime_videocontent_Submission_Template.ipynb
│   # Primary EDA notebook
│
└── README.md
    # Project documentation
```

## 🚀 Key Insights & Features

### 🎬 Content Type Analysis

* Compares **Movies** and **TV Shows**.
* Examines the distribution of different content types.
* Identifies which type dominates the Amazon Prime catalog.

### 🎭 Genre & Category Analysis

* Identifies the most common genres.
* Analyzes category and genre distributions.
* Finds patterns in the types of content available on the platform.

### 📅 Release & Temporal Trends

* Analyzes content based on release year.
* Examines how the content catalog has changed over time.
* Identifies periods with increased content production or additions.

### 🔞 Rating & Maturity Analysis

* Analyzes content based on maturity ratings.
* Identifies the most common audience categories.
* Examines the distribution of content suitable for different age groups.

### ⏱️ Duration Analysis

* Analyzes movie durations.
* Examines TV show season counts where available.
* Identifies common content-duration patterns.

## 🚀 Getting Started

### Prerequisites

Make sure you have the following installed:

* Python **3.8 or higher**
* Jupyter Notebook or JupyterLab
* Google Colab (optional)

### Installation

#### 1. Clone the Repository

```bash
git clone https://github.com/banul25/amazon-prime-EDA-project.git
```

Navigate to the project directory:

```bash
cd amazon-prime-EDA-project
```

#### 2. Install Required Dependencies

Install the required Python packages:

```bash
pip install pandas numpy matplotlib seaborn jupyterlab
```

Alternatively, if Jupyter Notebook is preferred:

```bash
pip install notebook
```

## 💻 Usage

### Run the Notebook Locally

Launch Jupyter Notebook:

```bash
jupyter notebook
```

Then open:

```text
EDA_of_amazon_prime_videocontent_Submission_Template.ipynb
```

### Run Using JupyterLab

You can also start JupyterLab:

```bash
jupyter lab
```

Then open the same notebook from the JupyterLab interface.

### Run Using Google Colab

The notebook can also be uploaded to **Google Colab** and executed in a cloud-based environment without requiring local Python setup.
